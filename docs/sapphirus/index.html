04 이전 게임 대화 학습에서 확인한 것
SMALL-SAMPLE DIAGNOSTICS

      

        
하나의 현재 Chat을 이어서 학습
일상 대화 24,030개를 학습한 r7에서 Minecraft 상황 대화 200개를 추가 학습했습니다. 시스템 메시지·공통 자연어 지시 없이, 필요한 상태를 구조화한 사용자 입력으로 전달합니다.
r7 → Minecraft 대화 누적본 → 멀티턴 누적본
이 절의 표와 위의 Minecraft 비교는 당시 r7과 게임 대화 누적본의 기록입니다. 최신 현재 기준은 멀티턴 누적본 하나입니다. 성공한 학습은 부모 가중치를 확인한 뒤 기준을 갱신하고, 이전 체크포인트는 이력으로 보존합니다. 현재 모델 선택과 실제 서비스 연결은 별개입니다.

05 근거와 공개 범위
INSPECT THE RECORD

      
실제 생성 기록, 선별 공개
직접 작성한 합성 평가 입력의 실제 모델 응답입니다. 이전 게임·일상 62쌍·124답변과 최신 멀티턴50쌍·100답변을 각각 모델 이름을 가린 상태에서 Codex가 수동 판정했습니다. 독립적인 사람 평가나 표준 벤치마크를 주장하지 않습니다.
평가 자료는 spent 상태이며 재실행·학습 재사용하지 않습니다. 해시는 원본 버전 식별값이며 비공개 원본 전체의 재현성을 보장하지 않습니다. 이 페이지는 모델·게임·Discord에 연결하지 않습니다.
