# 현재 모델 학습 — Rubrum / Sapphirus

기준일: **Rubrum 2026-10-30 / Sapphirus 2026-10-22**. 개인용 한국어 AI 컴패니언을 위한 현재 모델 연구를 정리합니다. [README](../README.md) · [근거 집계](../evidence/model-training/current-summary.json)

현재 기반 모델은 Rubrum의 **JetLM/SDAR-4B-Chat**, Sapphirus의 **Qwen3.5-4B**입니다. 두 프로젝트는 공개 사전학습 모델에 적응 학습을 진행합니다. 기존 BERT·Qwen3-8B 문서는 이전 설계와 실험의 이력입니다.

## Rubrum: 256 uniform + SC 대화·게임 연구

현재 구조와 최신 수치는 [Rubrum 현재 구조·검증 범위](rubrum-current-architecture.md)에 정리했습니다. SDAR backbone은 고정하고 attention·MLP LoRA(rank 8, alpha 16)와 FP32 self-conditioning 경로를 학습합니다. 생성 방식은 256-token uniform 노이즈 복원입니다.

증류 대화 전체 20,830개 대화·22,284개 assistant 대상 학습 후, 게임 근거 대화 500행 중 450행을 1 epoch 이어서 학습했습니다. 본문 7,475토큰, 실제 턴 종료 450개, EOS 채움 107,275개, 57 updates입니다. 별도 GameLoRA·8개 의미 헤드는 발화에서 구조화 목표를 읽으며, 생성 답변 품질이나 실행 성공과는 별도 평가합니다.

게임 50문항·일상 20문항 × 3 노이즈 수준의 복원 진단과 전후 총 60개 자유 생성을 구분했습니다. 게임 본문 loss는 1.842505 → 1.671623, 일상은 1.815562 → 1.835818입니다. 작은 비블라인드 생성 표본으로 전체 개선·악화를 단정하지 않고 최신 가중치에서 누적 학습을 이어가는 정책을 유지합니다.

[실제 디퓨전 Trace 뷰어](diffusion-trace/index.html)는 선별한 합성 평가 2건의 초기 노이즈부터 종료까지를 공개합니다. 10월 22일 누적 32,113,100 본문 토큰 기록은 [근거 JSON](../evidence/model-training/current-summary.json)의 history에 보존하며 최신 전체 누적으로 사용하지 않습니다.

## Sapphirus: 한국어 일상 대화 AR SFT

Qwen3.5-4B를 기반으로 언어 계층의 LoRA를 학습합니다. 최근 후보 r7은 r6 어댑터에서 이어서 학습했으며, 이번 코퍼스에 대한 1 epoch입니다. r7 전체 계보의 누적 학습 횟수와 구분합니다.

실행 식별자: `daily_chat_sft_24030_20261018_r7`. 실제 학습 실행일은 **2026-10-19**입니다.

| 항목 | 기록 |
| --- | --- |
| 학습 코퍼스 | 24,030개 대화 |
| Assistant 학습 대상 | 24,122개 |
| 학습 설정 | BF16, batch 16, gradient checkpointing |
| 학습 대상 | 답변과 종료 토큰, 문맥 loss 제외 |
| 시스템·공통 지시 | 사용하지 않음 |
| LoRA | rank 8, alpha 16, dropout 0.05 |
| 학습 파라미터 | 16,232,448개 |
| 이번 실행 | 1 epoch, 1,508 optimizer steps |
| 평균 학습 loss | 1.987834 |
| 전체 실행 시간 | 4,833.28초 |

저장 어댑터의 496개 tensor가 언어 계층 LoRA이며 유한값인지 CPU 검사로 확인한 기록이 있습니다. 학습 검증 자체에는 전체 모델 재로딩이 포함되지 않았고, 후속 답변 비교에서 r6/r7 어댑터를 각각 로드했습니다.

### 평가에서 확인한 범위

재사용 100문항의 토큰 가중 검증 loss는 **2.452236 → 2.362164**였습니다. 새 holdout 성적이나 생성 답변 품질 점수로 사용하지 않습니다.

별도로 새로 선정한 24문항(단일턴 20개·짧은 문맥 4개)에 r6/r7을 BF16·greedy 조건으로 실행했습니다. 모델 이름을 가린 두 검토의 쌍대 선호는 다음과 같습니다.

| 검토 | r7 선호 | r6 선호 | 동률 |
| --- | ---: | ---: | ---: |
| 1차 | 12 | 3 | 9 |
| 별도 검토 | 13 | 2 | 9 |

48개 답변은 모두 정상 종료했고 잘린 답변은 없었습니다. 이 표본에서는 r7의 일상 반응이 더 자주 선호됐지만, 일정 정정 반영과 짧은 대화에서 직접 답을 찾아내는 문제는 남았습니다.

이는 24문항의 주관적 진단이며 표준 benchmark나 전체 성능 보장이 아닙니다. 평가자 유형은 원본 집계에서 확인되지 않아 독립적인 사람 평가로 주장하지 않습니다. 평가 문항·대화 문맥·모델 답변은 학습 자료로 재사용하지 않습니다.

## 실행 모델과 학습 후보의 구분

Rubrum은 학습된 대화 LoRA의 Discord 연결과 최신 의미 헤드의 제한된 실제 Minecraft 관찰·이동을 별도 시험했습니다. 현재 상시 실행이나 최신 후보의 모든 기능 성공을 뜻하지 않습니다. 이번 문서·뷰어 갱신은 모델·게임·Discord를 실행하지 않습니다. Sapphirus의 r7 승격 여부와 실행 구성은 10월 22일 확인 범위를 유지합니다.

## 다음 연구 방향과 공개 범위

Rubrum의 다음 과제는 상태 입력 계약, 요청 의미와 실행 가능성의 분리, 수량·수령·부분 성공의 근거 대화입니다. 학습된 행동 Ranker와 자율 장기 계획은 완료되지 않았습니다. inZOI는 후속 연결 후보입니다.

[공개 근거 JSON](../evidence/model-training/current-summary.json)은 원본 기록에서 선별한 집계와 SHA-256을 제공합니다. 합성 평가 Trace 두 건을 제외한 원문 학습·평가 코퍼스, 개인 대화·계정·경로·가중치는 공개하지 않습니다. 해시는 원본 버전 식별용이며 학습 전체 재현성을 대신하지 않습니다. 이전 구현은 [공개 구현 목차](../companions/README.md)에 보존합니다.
