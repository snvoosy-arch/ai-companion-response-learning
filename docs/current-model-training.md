# 현재 모델 학습 — Rubrum / Sapphirus

기준일: **2026-10-22**. 개인용 한국어 AI 컴패니언을 위한 현재 모델 연구를 정리합니다. [README](../README.md) · [근거 집계](../evidence/model-training/current-summary.json)

현재 기반 모델은 Rubrum의 **JetLM/SDAR-4B-Chat**, Sapphirus의 **Qwen3.5-4B**입니다. 두 프로젝트는 공개 사전학습 모델에 적응 학습을 진행합니다. 기존 BERT·Qwen3-8B 문서는 이전 설계와 실험의 이력입니다.

## Rubrum: 디퓨전 생성 적응

SDAR-4B-Chat을 바탕으로 256-token canvas에 균일 토큰 노이즈를 적용하고 이를 복원하는 학습을 연구합니다. Backbone은 고정하고 attention·MLP의 LoRA(rank 8, alpha 16)와 FP32 self-conditioning residual 경로를 학습합니다. 이전 예측 분포의 임베딩 정보를 다음 복원 단계에 반영하는 구조입니다.

### 최신 검증 완료 단계

실행 식별자: `fineweb_uniform_300steps_20261022`. FineWeb 계열 본문을 이용한 계속학습으로, 저장된 200-step 지점에서 재개해 300-step 단계를 마쳤습니다.

| 항목 | 기록 |
| --- | ---: |
| 이번 단계 본문 토큰 | 551,426 |
| 이번 단계 학습 canvas | 2,400 |
| 이번 단계 optimizer updates | 300 |
| 누적 처리 본문 토큰 | 32,113,100 |
| 누적 optimizer updates | 17,549 |
| 저장 파일·재개 상태 검사 | 51개 통과 |
| 저장 checkpoint 재로딩 비교 | 고정 표본 3개 일치 |

누적 토큰 수는 이 프로젝트가 적응 학습에서 처리한 본문 토큰 집계입니다. 원본 SDAR의 사전학습 규모나 고유 문서 수를 뜻하지 않습니다. 원본 모델과 이번 학습 후보는 별도로 유지하며 runtime 변경은 하지 않았습니다.

### 복원 평가와 생성 평가

고정된 100개 문서를 세 노이즈 수준(0.1·0.5·0.9)에 적용한 총 300개 조건으로 평가했습니다.

| 본문 영역 복원 지표 | 직전 단계 | 이번 단계 |
| --- | ---: | ---: |
| Loss | 2.439341 | 2.432136 |
| 토큰 정확도 | 61.69% | 61.92% |

이 수치는 노이즈가 있는 입력의 본문 복원 성적입니다. 대화 성공률이나 자연스러움 점수가 아니며, 반복 사용하는 고정 진단입니다.

별도의 자유 생성 20건에서는 빈 답변 1건, 대체 문자(U+FFFD) 0개가 기록됐습니다. 의미 품질은 추가 검토가 필요합니다. 생성 비교는 seed를 고정하거나 난수를 짝지은 실험이 아니므로 작은 표본 차이를 학습의 인과적 개선으로 확정하지 않습니다.

이 단계의 자동 보고서 제목에는 이전 날짜·‘백만 토큰’ 문구가 남아 있어, 본 문서는 검증된 실행 메타데이터의 날짜와 실제 551,426-token 집계를 사용합니다.

## Sapphirus: 한국어 일상 대화 AR SFT

Qwen3.5-4B를 기반으로 언어 계층의 LoRA를 학습합니다. 최근 후보 r7은 r6 어댑터에서 이어서 학습했으며, 이번 코퍼스에 대한 1 epoch입니다. r7 전체 계보의 누적 학습 횟수와 구분합니다.

실행 식별자: `daily_chat_sft_24030_20261018_r7`. 실제 학습 실행일은 **2026-10-19**입니다.

| 항목 | 기록 |
| --- | --- |
| 학습 코퍼스 | 24,030개 대화 |
| Assistant 학습 대상 | 24,122개 |
| 학습 설정 | BF16, batch 16, gradient checkpointing |
| 학습 대상 | 답변과 종료 토큰, 문맥 loss 제외 |
| 시스템·공통 지시 | 사용하지 않음 |
| LoRA | rank 8, alpha 16, dropout 0.05 |
| 학습 파라미터 | 16,232,448개 |
| 이번 실행 | 1 epoch, 1,508 optimizer steps |
| 평균 학습 loss | 1.987834 |
| 전체 실행 시간 | 4,833.28초 |

저장 어댑터의 496개 tensor가 언어 계층 LoRA이며 유한값인지 CPU 검사로 확인한 기록이 있습니다. 학습 검증 자체에는 전체 모델 재로딩이 포함되지 않았고, 후속 답변 비교에서 r6/r7 어댑터를 각각 로드했습니다.

### 평가에서 확인한 범위

재사용 100문항의 토큰 가중 검증 loss는 **2.452236 → 2.362164**였습니다. 새 holdout 성적이나 생성 답변 품질 점수로 사용하지 않습니다.

별도로 새로 선정한 24문항(단일턴 20개·짧은 문맥 4개)에 r6/r7을 BF16·greedy 조건으로 실행했습니다. 모델 이름을 가린 두 검토의 쌍대 선호는 다음과 같습니다.

| 검토 | r7 선호 | r6 선호 | 동률 |
| --- | ---: | ---: | ---: |
| 1차 | 12 | 3 | 9 |
| 별도 검토 | 13 | 2 | 9 |

48개 답변은 모두 정상 종료했고 잘린 답변은 없었습니다. 이 표본에서는 r7의 일상 반응이 더 자주 선호됐지만, 일정 정정 반영과 짧은 대화에서 직접 답을 찾아내는 문제는 남았습니다.

이는 24문항의 주관적 진단이며 표준 benchmark나 전체 성능 보장이 아닙니다. 평가자 유형은 원본 집계에서 확인되지 않아 독립적인 사람 평가로 주장하지 않습니다. 평가 문항·대화 문맥·모델 답변은 학습 자료로 재사용하지 않습니다.

## 실행 모델과 학습 후보의 구분

| 구분 | Rubrum | Sapphirus |
| --- | --- | --- |
| 연구 후보 | SDAR 기반 LoRA + self-conditioning | Qwen3.5-4B r7 LoRA |
| 확인한 Discord 코드 | 원본 SDAR + 한국어 의미 헤드 | 원본 Qwen3.5-4B, LLM.int8 |
| 최신 학습 후보 배포 | 이번 연구 단계에서 runtime 변경 없음 | r7 승격 없음 |
| 게임 연결 | 이전 BERT 계보의 Minecraft 코드와 구분 | 이전 Qwen3-8B 계보의 Minecraft 코드와 구분 |

이 표는 코드와 저장된 실행 기록에서 확인한 구성입니다. 현재 서비스가 실행 중이라는 실시간 상태 확인은 아닙니다. 최신 두 후보가 Minecraft 또는 inZOI를 플레이했다는 결과도 포함하지 않습니다.

## 다음 연구 방향

개인 AI와의 공동 플레이를 위해 Minecraft를 우선 대상으로 삼습니다. 다음 학습 과제는 게임 상태·사용자 요청에 맞는 행동 선택, 정정에 따른 목표 변경, 실제 행동 결과와 대화의 일치입니다. inZOI 연결은 후속 실험 후보입니다. 이 항목들은 계획이며 완료된 기능이나 평가 결과가 아닙니다.

## 근거와 공개 범위

[공개 근거 JSON](../evidence/model-training/current-summary.json)은 원본 기록에서 필요한 숫자·실험 조건만 선별하고 원본 SHA-256을 붙였습니다. 학습 데이터, 대화 원문, 계정·채널 식별자, 개인 경로와 모델 가중치는 복사하지 않았습니다.

원본 실행 기록은 로컬 연구 자료에 보존되어 있습니다. 해시는 근거의 버전을 식별하지만 원본 내용의 공개 검증이나 학습 재현성을 대신하지 않습니다. 현재 공개 코드는 [이전 구현 목차](../companions/README.md)에서 확인할 수 있습니다.
