# Sapphirus — 현재 구조와 확인한 범위

기준일 **2026-10-30**. [실제 답변 비교](https://snvoosy-arch.github.io/ai-companion-response-learning/sapphirus/) · [공개 집계](../evidence/model-training/current-summary.json) · [CPU 코드](../examples/sapphirus_current/README.md)

생성형 모델이 말과 고수준 행동을 제안하고 권한·실행·관측 근거·전달은 외부 시스템이 맡는 한국어 AI 컴패니언이다. Qwen3.5-4B의 Chat과 Game LoRA를 분리한다. 최신 두 LoRA의 전체 게임 실행 루프는 아직 미연결이다.

## 현재 Chat과 누적 학습

현재는 `chat_continuation_multiturn250_20261030_r1`다. r7 → Minecraft 상황 대화200개 누적본 → 짧은 멀티턴200개 누적본으로 이어진다. 매번 최신 가중치에서 시작하고 정상 학습·저장·tensor·부모 검증 뒤 현재 선택을 갱신한다. 이전 파일은 독립 후보가 아닌 이력이다. optimizer/scheduler는 새 실행에서 초기화한다.

| 항목 | 이번 실제 기록 |
| --- | --- |
| 새 자료 | 학습200대화·450 assistant 대상 / 개발50대화·110대상 |
| 학습 | BF16 원본, 언어층 rank8/alpha16 LoRA,1epoch·29steps |
| 평균 학습loss | 2.091408 |
| 같은 개발loss | 2.065108 → 1.947580 |
| 학습 구간 | 1093.67초 |
| 현재 adapter SHA-256 | `b5f98bae4dd2043110a4d6fdd4bc2af5371268823218e66dcf640b88c71a6901` |

범용 계속학습 진입점의 첫 실제 GPU 실행을 완료했다. 시스템·공통 자연어 지시 없이 user/assistant와 종료 토큰을 학습하며 입력 문맥은 loss에서 제외한다. 원문은 문항별 직접 작성한50개씩5묶음이고 템플릿·seed 문장 확장·학생 출력 재활용이 없다.

## 새 최종50, 실제 답변100개

가중치를 고정한 뒤 새50문항을 작성했다. 같은 고정 문맥에 이전/현재를 각각1회 생성했다. BF16 base와 정확히 로드한 FP32 LoRA, greedy, 공통 지시 없이100개 모두 정상 종료했다. 모델 이름을 가린 Codex 수동 판정이며 독립 사람 평가·표준 벤치마크가 아니다.

| 판정 | 이전 | 현재 |
| --- | ---: | ---: |
| 문맥·요청 충족 / 사용 가능 |41/50|42/50|
| 표현 평균 /2 |1.60|1.62|
| 쌍대 선호 |14|11|
| 동률 |25|25|

**작은 혼합 결과다.** 수첩 구분 이유 설명이나 대화 전환에서 나아진 사례가 있지만 취소·주제 전환의 후퇴도 있다. 수량·색 정정 누락과 문맥 없는 약속에 대한 동의는 양쪽에 남았다. loss 감소를 전체 품질 향상의 증거로 대체하지 않는다. 현재 선택을 작은 점수로 자동 롤백하지 않는다.

문맥 충족과 표현을 분리한다. 자연스러운 오답도 남기며 사용 가능은 문맥/요청 충족·표현1이상·정상 종료·전달 형식 충족이다. 화면의6쌍은 개선2·공통 오류2·후퇴2를 선별한 것으로 대표 표본이 아니다. 앞 답변은 직접 작성한 고정 문맥이며 실제 자율 멀티턴 rollout 점수가 아니다. 최종 자료는 spent로 보존하고 재실행·학습에 쓰지 않는다.

## 모델 우선 문맥과 자료 경계

대화 의미·주제 전환을 키워드로 선판단하지 않는다. 외부 코드는 같은 사용자·채널의30분 내 완전한 최대2쌍과 유효한 명시적 답글을 전달하고 모델이 관련성을 해석한다. 수정·삭제된 근거의 생성/전송 취소와 요청ID·정상 종료·본문 경계는 외부가 유지한다.

학습 자료 원장은 Chat/Game·계약·split·hash·실제 노출 이력을 구분한다. 등록된 reviewed Chat train/dev만 읽고 보호된 평가 입력의 정규화 exact fingerprint를 확인한다. 이는 대화 필터나 의미 유사도 검사, 수동 작성 과정의 완전한 증명은 아니다. 과거 DB 검색을 모델이 선택하는 기능은 아직 연결하지 않았다.

## 이전 기록과 실행 범위

이전 r7→Minecraft Chat50쌍의 사용 가능26→33과 일상12쌍은 [별도 보존 집계](../docs/sapphirus/data/comparison.json)다. 최신 멀티턴 점수와 같은 표본이 아니다. Game joint53의 최종32/50은 출력 평가이며53개 실행기를 뜻하지 않는다. 이전 제한 서버 시험의 두 행동은 인자로 거절돼 실제 이동·채집0회였다.

이번에는 사용자가 Minecraft를 건너뛰도록 요청했다. Game 가중치·실행기·통합 host와 실제 서버/봇은 변경·실행하지 않았다. Discord·영속 기억·보호된 active runtime/freeze도 유지했다. 모델 선택은 서비스 배포와 별개이며 시험 모델은 종료한다.
