02 이 기록을 읽는 법

        
A / PROCESS
뒤의 토큰도 다시 바뀝니다.
왼쪽부터 한 토큰씩 확정하는 AR과 달리, 이 실험은 256칸의 canvas를 함께 복원합니다. 선택된 위치도 다음 단계에서 다시 바뀔 수 있습니다. 이전 예측은 self-conditioning에 반영됩니다.

        
B / BOUNDARY
수렴과 사실성은 다릅니다.
Entropy는 모델의 예측 분포를 나타냅니다. 관찰과 일치하는 확률이나 의미 정확도 점수가 아닙니다. 잘못된 수령 주장도 안정적으로 수렴했습니다. 행동 결과와 발화의 대조가 별도로 필요합니다.

        
C / EVIDENCE
생성 과정을 공개합니다.
직접 작성한 합성 평가 상황에서 저장한 실제 모델 기록입니다. 개인 Discord 대화나 실제 게임 플레이 로그가 아닙니다. 두 사례는 과정 설명을 위해 선별했으며 전체 성능을 대표하지 않습니다.

      


      
SOURCE & REPRODUCTION
기록을 재생할 뿐,
모델을 실행하지 않습니다.
정적 파일만으로 작동하며 GPU·API 키·모델 서버가 필요 없습니다. 모델 가중치와 전체 학습 코퍼스는 포함하지 않습니다. Trace는 재생할 수 있지만, 공개 파일만으로 학습 전체를 재현할 수 있다는 뜻은 아닙니다.
토큰은 완성된 단어가 아닐 수 있습니다. 개별 조각의 �는 UTF-8 바이트 조각을 따로 해독한 결과일 수 있으므로, 연결된 텍스트와 토큰 ID를 함께 확인하세요. 초기 노이즈는 정제하지 않았습니다.
